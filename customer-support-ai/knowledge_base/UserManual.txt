TechMart Electronics — User Manual & Troubleshooting Guide
==========================================================

GETTING STARTED
---------------
1. Unbox your device and connect the power adapter.
2. Press and hold the power button for 3 seconds.
3. Follow the on-screen setup wizard (language, Wi-Fi, account sign-in).
4. Install TechMart Suite software from techmart.com/downloads.
5. Activate your product with the license key in the box or in your order email.

ACCOUNT SETUP
-------------
Creating an Account:
  - Go to techmart.com → click "Sign Up"
  - Enter name, email, and password (min 8 characters, 1 uppercase, 1 number)
  - Verify your email address within 24 hours
  - Enable Two-Factor Authentication (recommended): Account → Security → 2FA

TROUBLESHOOTING — LOGIN ISSUES
--------------------------------
Problem: Can't log in to TechMart account
Solution:
  1. Check you're using the email address registered at sign-up.
  2. Click "Forgot Password" and reset via email link.
  3. Clear browser cache: Settings → History → Clear Browsing Data.
  4. Disable browser extensions (ad blockers can interfere).
  5. Try a different browser or device.
  6. If 2FA is failing, use backup codes sent at setup or contact support.

Problem: Account locked after failed attempts
Solution:
  - Accounts lock after 5 failed login attempts for 30 minutes.
  - Wait 30 minutes or reset your password immediately to unlock.
  - Contact support if you believe your account was compromised.

TROUBLESHOOTING — SOFTWARE INSTALLATION
-----------------------------------------
Problem: Installer fails to run
Solution:
  1. Right-click installer → "Run as Administrator."
  2. Temporarily disable antivirus software during installation.
  3. Ensure .NET Framework 4.8+ is installed (Windows).
  4. Free up at least 2 GB disk space.
  5. Download a fresh installer from techmart.com/downloads.

Problem: Software crashes on launch
Solution:
  1. Update to the latest version: Help → Check for Updates.
  2. Restart your computer.
  3. Run in compatibility mode (Windows: right-click → Properties → Compatibility).
  4. Reinstall: Control Panel → Programs → Uninstall → Reinstall fresh copy.

TROUBLESHOOTING — DEVICE PERFORMANCE
--------------------------------------
Problem: Laptop running slowly
Solution:
  1. Restart the laptop.
  2. Check Task Manager for high CPU/memory processes.
  3. Update Windows/macOS and all drivers.
  4. Run TechMart System Optimizer: Settings → Performance → Optimize.
  5. If battery life is poor: Settings → Power → Battery Saver mode.

CONNECTIVITY
------------
Wi-Fi not connecting:
  1. Forget the network and reconnect.
  2. Restart router and laptop.
  3. Update Wi-Fi drivers from Device Manager.
  4. Run Windows Network Troubleshooter.

HARDWARE WARRANTY SERVICE
--------------------------
If hardware is defective:
  1. Document the defect with photos or video.
  2. Email warranty@techmart.com with order number and media.
  3. A warranty claim will be opened within 24 hours.
  4. Approved claims: free repair, replacement, or refund within 10 business days.

FACTORY RESET
-------------
WARNING: This erases all data. Back up first.
Windows: Settings → System → Recovery → Reset this PC
macOS:   Restart → Hold Cmd+R → Disk Utility → Erase → Reinstall macOS
